# LinkShelf Mover（v1.0.0 正式版辅助工具）

LinkShelf 主程序专注管理**已有**目录连接点与符号链接；Mover 与主程序在同一 v1.0.0 发行包中，独立运行，负责把普通 NTFS 文件夹迁至另一目录，并在原位置建立 `/J` 连接点或 `/D` 目录符号链接（默认 `/J`）。主程序的索引、配置和其他功能不受影响。

## 使用

1. 完整解压 LinkShelf v1.0.0 包，运行 `LinkShelfMover.exe`，单击 **加入「发送到」菜单**。仅在当前 Windows 用户的 SendTo 目录创建快捷方式，不安装 Shell 扩展、服务或注册表项。
2. 在资源管理器中右键单个普通文件夹，选择 **发送到 → LinkShelf - 移动并建立目录连接点**（Windows 11 可能位于「显示更多选项」内）。
3. 选择目标父目录。例如右键 `C:\A`，浏览 `D:\B`，目标自动成为 `D:\B\A`；末尾的 `A` 可以自行修改，目标完整路径也允许直接编辑。
4. 通过 **链接类型** 选择 `/J` 或 `/D`（默认 `/J`）；关闭占用源目录的应用，点击 **检查并开始迁移**。此操作真实迁移文件，成功后 `C:\A` 是连接到 `D:\B\A` 的目录链接。
5. 若要移除菜单，再运行程序，单击 **从「发送到」菜单移除**。请勿在保留菜单快捷方式时随意移动 EXE 文件，否则快捷方式将失效。

窗口大小和位置会记忆；首次启动或上次使用的显示器已断开时居中显示。优先在程序目录保存设置，目录无写权限时存入用户配置目录。

需要 Windows x64、.NET 8 Desktop Runtime x64。**不需要 Everything 运行**。本工具与 LinkShelf 主程序同仓库，独立构建。

## 安全策略与局限

- 严格检查完整路径、本地固定 NTFS、目录存在及目标冲突；拒绝磁盘根目录、系统保护目录、目录自身及父级重解析点。
- 遍历源目录，拒绝内部重解析点（包括云盘占位符、符号链接、连接点）、EFS 加密、只读文件、硬链接，以及无法访问或无法取得删除权限的文件/子目录。
- 提前检查源目录的重命名权限、源父目录和目标父目录的创建/删除权限、目标可用容量。
- 复制到目标盘独立临时目录，使用 `robocopy /E /COPY:DATS /DCOPY:DAT` 保留文件数据、时间、属性及 NTFS DACL；保留备用数据流（ADS）。对每个文件主数据流进行 SHA-256 核对，并复查文件清单、大小、修改时间和空目录。
- 通过所有校验后，先将原目录临时改名为同盘备份，再将目标暂存目录改成最终名称，然后按照用户选择创建并验证原位置 `/J` 或 `/D`。若过程中失败，尽可能自动回退。
- 只有确认连接点正确后才删除原目录备份；如果删除失败，连接点仍然有效，显示备份具体路径以便手工处理。迁移阶段记录在 `%LOCALAPPDATA%\LinkShelf\Mover`；异常退出后重新打开工具会尝试提示恢复源目录。
- **不能做到真正的跨盘原子事务**：检查通过后仍可能有新文件被其他进程打开/修改；系统断电也可能中断提交。重要目录仍需事先备份并关闭相关应用。
- 迁移至另一个 NTFS 卷后，文件系统所有者、审核规则（SACL）和硬链接语义不保证完全一致；当前预检拒绝硬链接文件。请先用非关键目录测试。
- 遇到 Windows `错误 5 / 0x00000005` 时显示受影响路径和 Unicode 错误日志，并询问是否通过 UAC **以管理员身份重新打开**；原路径与目标路径自动保留，但**不会直接执行迁移**，需要用户再次确认。UAC 被取消时原窗口仍保留。
- `/D` 创建通常需要管理员权限；Windows 开启开发者模式也可允许普通用户创建目录符号链接。创建失败时仍按原流程尝试恢复原目录；提权重开会保留选定的 `/D` 类型。为保证安全，Mover 仍只迁移本地 NTFS 目录，不开放网络迁移。
- 复制、校验期间可取消；进入切换连接点阶段后不能取消，也不能直接强制关机。

## 编译和 Windows 本机测试

```powershell
dotnet publish Tools/LinkShelfMover/LinkShelfMover.csproj -c Release -r win-x64 --self-contained false -o Build/Mover
dotnet run --project Tools/LinkShelfMover.Tests/LinkShelfMover.Tests.csproj -c Release
```

测试程序只操作自动创建的 `%TEMP%\LinkShelfMover_native_tests_<随机值>` 目录，测试正常移动、Unicode 文件、目录链接、文件占用、目标冲突、内部重解析点、只读文件及取消。`/J` 和 `/D` 的实际迁移已由用户在 Windows 本机验收；GitHub Actions 也会运行 Windows 原生测试。Linux 构建检查**不能替代 Windows 原生测试**。
