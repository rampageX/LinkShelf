LinkShelf 0.1.4 Stable

运行：解压整个文件夹，双击 LinkShelf.exe。
EXE 图标与窗口左上角统一使用 Windows Forms 标准图标；鼠标悬停及文件属性可查看文件版本、产品版本、说明、作者标识和版权信息。
要求：Windows 10/11 x64、.NET 8 Desktop Runtime x64；Everything 客户端已运行。
如缺少运行时： https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
选择 .NET Desktop Runtime 的 Windows x64 安装程序。

1. 自动连接已运行的 Everything 实例，可在左上角选择实例。
2. 从 Everything 已有索引读取 folder: attrib:L，程序识别目录连接点和目录符号链接。
3. 默认隐藏带系统属性的链接；取消勾选可查看。带系统属性的项目和卷挂载点只读。
4. 点击“计算当前列表”统计目标目录大小，或右键计算所选。
5. “仅 C 盘转出”方便查看移出 C 盘的数据；列头点击排序。
   主表格按窗口宽度自动分配列宽，路径列优先扩展，状态列保持紧凑；仅必要时显示水平滚动条。
   窗口、筛选及链接类型下拉框已改为完整暗色绘制；禁用按钮也使用清晰的灰色文字。
6. 双击打开目标；右键定位、复制、新建之外的管理操作。新建使用上方按钮。
7. 窗口大小、位置、最大化状态、列宽比例及实例记忆在程序旁边。

统计口径：
- C 盘转出总量基于所有已发现的非系统属性链接，与当前搜索筛选无关。
- 只累计 C: 链接指向其他本地盘的逻辑文件大小；相同、嵌套、已解析别名目标去重。
- 未计算和异常/部分结果会标出；“*”代表大小不完整。
- 不跟随目标内部重解析点，防止循环和重复统计；网络目标暂不统计。
- 数量来自当前文件，不代表历史释放空间或实际物理占用；压缩、稀疏文件和文件硬链接均可能影响估算。
- 结果只缓存在本次运行中；文件改变后右键强制重算。停止请求在文件系统调用返回后生效。
- Everything 未索引的盘符或被排除的目录不会出现在列表；不会重新遍历全盘寻找链接。

写操作：
- 首版不搬迁普通文件夹，修改指向不移动文件。
- 删除仅删除打开并核实过的链接对象，不递归删除目标。
- 修改指向通过重解析点句柄更新，并检查旧关系是否变化。
- 写操作前在 LinkShelf.operations.jsonl 记录旧路径、目标和原始重解析数据。
- 新建链接路径必须不存在，目标目录必须存在。符号链接可能需要开发者模式或管理员权限。
- 目标处于使用中时请退出相关软件后再管理。
