LinkShelf 1.0.1 Stable

v1.0.1：修复 LinkShelfMover.exe 成功迁移后日志仍停在“正在清理原目录备份”的问题。实际清理完成后会明确写入最终成功消息；清理失败则继续显示源备份路径和警告。主程序 LinkShelf.exe 与 Mover 两款工具同包发布，支持 /J、/D，永久缓存和新链接高亮置顶继续保留。

运行：完整解压发布包，双击 LinkShelf.exe（管理）或 LinkShelfMover.exe（迁移）。
EXE 图标与窗口左上角统一使用 Windows Forms 标准图标；鼠标悬停及文件属性可查看文件版本、产品版本、说明、作者标识和版权信息。
要求：Windows 10/11 x64、.NET 8 Desktop Runtime x64；使用 LinkShelf.exe 时 Everything 客户端需已运行，Mover 不需要 Everything。
如缺少运行时： https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
选择 .NET Desktop Runtime 的 Windows x64 安装程序。

1. 自动连接已运行的 Everything 实例，可在右侧操作工具栏选择实例。
2. 从 Everything 已有索引读取 folder: attrib:L，程序识别目录连接点和目录符号链接。
3. 默认隐藏带系统属性的链接；取消勾选可查看。带系统属性的项目和卷挂载点只读。
4. 点击“计算当前列表”统计目标目录大小，或右键计算所选。结果永久保存，下次运行直接恢复；第二行统计信息末尾“缓存大小”后的“更新”文字链接可强制重算本实例的本地非系统目标。“连接 / 刷新”只更新 Everything 链接列表，不重新计算已有大小。
5. “仅 C 盘转出”方便查看移出 C 盘的数据；列头点击排序。新发现链接绿色高亮置顶，新增/原有两组内部遵守当前排序，组间只有细暗色分隔带。
   主表格按窗口宽度自动分配列宽，路径列优先扩展，状态列保持紧凑；仅必要时显示水平滚动条。
   窗口、筛选及链接类型下拉框已改为完整暗色绘制；禁用按钮也使用清晰的灰色文字。
6. 双击打开目标；右键定位、复制、新建之外的管理操作。新建使用上方按钮。
7. 窗口大小、位置、最大化状态、列宽比例及实例记忆在程序旁边。按 Everything 实例独立记录上次发现的链接；首次运行建立基线，不会把旧链接误判为新增。

便携数据：
- LinkShelf.settings.json：窗口与界面设置。
- LinkShelf.sizes.json：永久目标大小缓存、首次创建与最近更新时间。
- LinkShelf.links.json：每个 Everything 实例的上次链接列表，用于识别新增。
这些 JSON 文件在程序目录内自动生成，不包含在发行包中。覆盖升级时保留它们即可沿用历史缓存。

统计口径：
- C 盘转出总量基于所有已发现的非系统属性链接，与当前搜索筛选无关。
- 只累计 C: 链接指向其他本地盘的逻辑文件大小；相同、嵌套、已解析别名目标去重。
- 未计算和异常/部分结果会标出；“*”代表大小不完整。
- 不跟随目标内部重解析点，防止循环和重复统计；网络目标暂不统计。
- 数量来自当前文件，不代表历史释放空间或实际物理占用；压缩、稀疏文件和文件硬链接均可能影响估算。
- 大小结果跨运行保留，但不是实时数据；文件改变后点统计行末尾“更新”或右键强制重算。停止请求在文件系统调用返回后生效，已完成结果仍会持久保存。
- Everything 未索引的盘符或被排除的目录不会出现在列表；不会重新遍历全盘寻找链接。

写操作：
- 管理器的“修改指向”不搬迁文件；普通文件夹搬迁使用独立的 LinkShelfMover.exe。
- 删除仅删除打开并核实过的链接对象，不递归删除目标。
- 修改指向通过重解析点句柄更新，并检查旧关系是否变化。
- 写操作前在 LinkShelf.operations.jsonl 记录旧路径、目标和原始重解析数据。
- 新建链接路径必须不存在，目标目录必须存在。符号链接可能需要开发者模式或管理员权限。
- 目标处于使用中时请退出相关软件后再管理。

Mover 快速使用：
1. 运行 LinkShelfMover.exe，按“加入「发送到」菜单”，此操作仅为当前用户创建 SendTo 快捷方式，不注册 Shell 扩展、不安装服务。
2. 资源管理器右键单个普通文件夹 → 发送到 → LinkShelf - 移动并建立目录连接点。
3. 选择目标父目录。例如 C:\A 搬往 D:\B，则自动填写 D:\B\A；可手动编辑最终目标路径。
4. 选择“目录连接点 /J”（默认）或“目录符号链接 /D”，检查源目录、目标目录和文件占用后，点击“检查并开始迁移”。
5. 复制、校验通过后才切换原路径为链接；如遇错误 5 可选择 UAC 提权重开，源/目标/类型会保留，但需要再次手动确认迁移。
6. 搬迁操作真实修改数据，跨磁盘不可能完全原子化；重要目录请先备份，退出正在使用该目录的软件。
7. 需要更换 Mover.exe 所在目录时，请从旧位置移除「发送到」快捷方式，再从新位置重新安装。
更多注意事项及故障恢复说明见 README_Mover.md。
